Moovie Embed Docs

Moovie Embed

Stream proxy server with embeddable video player. 60+ media source scrapers.

Overview

Moovie Embed is a backend stream proxy that aggregates media sources from 60+ providers and makes them playable through a single, embeddable video player. The browser communicates only with this server — never directly with third-party providers.

Every provider URL is proxied through the backend. The scraper's required headers (Referer, Origin, User-Agent, etc.) are applied server-side. The frontend receives a proxy URL that works transparently.

How It Works

1. Client calls the Search API with a TMDB ID → 2. Server scrapes 60+ providers in parallel → 3. Each stream URL is replaced with a proxy URL pointing to this server → 4. The proxy fetches the actual stream from the provider with the correct headers → 5. HLS playlists are rewritten so segments also go through the proxy → 6. The client plays the stream without ever hitting the provider directly.

Search API

Search for movie or TV show streams by TMDB ID. Returns provider results with proxy URLs ready for playback.

Request

GET /api/search?q={TMDB_ID}&type={movie|tv}&season={S}&episode={E}
ParamTypeRequiredDescription
qstringyesTMDB ID (e.g. 550 for Fight Club)
typestringnomovie (default) or tv
seasonnumbernoSeason number for TV shows
episodenumbernoEpisode number for TV shows

Response

{
  "query": "550",
  "type": "movie",
  "totalStreams": 15,
  "results": [
    {
      "provider": "xpass",
      "providerName": "Xpass",
      "priority": 1,
      "count": 3,
      "servers": ["Xpass | 1080p", "Xpass | 720p"],
      "streams": [
        {
          "name": "Xpass | 1080p",
          "url": "https://cdn.provider.com/stream.m3u8",
          "proxyUrl": "/proxy?id=abc123",
          "type": "m3u8",
          "quality": "1080p",
          "headers": { "Referer": "https://provider.com" }
        }
      ]
    }
  ]
}

Each stream object contains:

FieldDescription
urlOriginal provider URL (for reference)
proxyUrlUse this for playback. Points to /proxy?id=...
typeMedia type: m3u8, mp4, mkv, mpd
headersHeaders required by the provider (applied server-side by proxy)
qualityResolution label: 1080p, 720p, etc.
nameDisplay name for the source

Proxy Endpoint

The proxy endpoint fetches stream data from the provider using the scraper's required headers. The browser never contacts the provider directly.

ID-based (from Search API)

GET /proxy?id={streamId}

The id is generated server-side during search and stored in memory. This is the recommended approach when using the Search API.

Inline (stateless)

GET /proxy?u={base64url_url}&h={base64url_headers}

Encodes the target URL and JSON headers as base64url. No server-side storage needed. This mode is used internally by HLS playlist rewriting and can be used directly for embedding.

The proxy forwards the client's Range header for seeking, streams the response with proper Content-Type, Content-Length, Content-Range, and Accept-Ranges headers, and follows redirects. HLS playlists (.m3u8) are rewritten so all segment requests also go through the proxy with the same headers.

Embed Player

The embeddable player at /embed provides a minimal, fullscreen video player. Just pass a TMDB ID — it handles the rest.

Parameters

ParamRequiredDescription
tmdbyes*TMDB ID (e.g. 550 for Fight Club)
typenomovie (default) or tv
seasonnoSeason number for TV shows
episodenoEpisode number for TV shows
titlenoTitle shown as overlay
autoplaynoSet to 1 to enable autoplay (disabled by default for embeds)

* Alternatively, use id (proxy ID from search) or u&h (base64 URL+headers) for direct stream access.

Code Examples

1. Simplest iframe Embed (TMDB ID only)

Just pass a TMDB ID — the embed searches for streams and plays the first available source:

<iframe
  src="https://scrapers.moovie.fun/embed?tmdb=550"
  width="100%"
  height="500"
  frameborder="0"
  allowfullscreen
  allow="autoplay; encrypted-media"
></iframe>

2. TV Show Embed

<iframe
  src="https://scrapers.moovie.fun/embed?tmdb=1399&type=tv&season=1&episode=1"
  width="100%"
  height="500"
  frameborder="0"
  allowfullscreen
  allow="autoplay; encrypted-media"
></iframe>

3. React Component

function MoovieEmbed({ tmdb, type, season, episode, width, height }) {
  var src = 'https://scrapers.moovie.fun/embed?tmdb=' + tmdb +
    (type ? '&type=' + type : '');
  if (season) src += '&season=' + season;
  if (episode) src += '&episode=' + episode;

  return (
    <iframe
      src={src}
      width={width || '100%'}
      height={height || 500}
      frameBorder="0"
      allowFullScreen
      allow="autoplay; encrypted-media"
    />
  );
}

// Usage
<MoovieEmbed tmdb={550} type="movie" />
<MoovieEmbed tmdb={1399} type="tv" season={1} episode={1} />

4. Programmatic Playback (without iframe)

Use the search + proxy API directly in your own player:

<video id="video" controls crossorigin></video>
<script src="https://cdn.jsdelivr.net/npm/hls.js@latest"></script>
<script>
fetch('https://scrapers.moovie.fun/api/search?q=550&type=movie')
  .then(r => r.json())
  .then(data => {
    var stream = data.results[0].streams[0];
    var url = stream.proxyUrl; // relative path, use full URL for external

    if (Hls.isSupported()) {
      var hls = new Hls();
      hls.loadSource(url);
      hls.attachMedia(document.getElementById('video'));
    }
  });
</script>

5. Direct Stream (proxy ID or inline)

If you already have a proxy ID or stream URL, you can pass it directly:

<!-- By proxy ID -->
<iframe src="https://scrapers.moovie.fun/embed?id=abc123"></iframe>

<!-- By inline URL + headers (base64url) -->
<iframe src="https://scrapers.moovie.fun/embed?u=...&h=..."></iframe>

API Reference

MethodEndpointDescription
GET/api/search?q=&type=&season=&episode=Search for streams by TMDB ID
GET/proxy?id=Proxy a stream by ID (from search results)
GET/proxy?u=&h=Proxy a stream by inline URL+headers (stateless)
GET/embed?id=&title=&autoplay=Embeddable video player (ID mode)
GET/embed?u=&h=&title=&type=Embeddable video player (stateless inline mode)
GET/api/providersList all providers and their status
POST/api/providers/:id/toggleToggle a provider on/off
POST/api/providers/toggle-allEnable or disable all providers
POST/api/providers/:id/prioritySet provider priority
POST/api/providers/:id/serversUpdate disabled sub-servers
GET/api/providers/:id/discoverDiscover available servers for a provider
GET/api/settingsGet server settings
PUT/api/settingsUpdate server settings
GET/api/infoGet server network information

Notes

Proxy IDs expire on server restart. Stream IDs are stored in memory. Restarting the server invalidates all existing IDs. Use the inline mode (?u=&h=) for persistent links.
HLS streams are fully proxied. The proxy rewrites master and variant playlists so every segment request also goes through the proxy with the same headers.
CORS is enabled globally. All API endpoints and the embed page can be loaded from any origin.
All requests go to the same server. Use scrapers.moovie.fun for API, proxy, embed, and docs — everything is served from a single endpoint.
